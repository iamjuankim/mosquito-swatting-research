# Rights and third-party material review

This package contains selected MQ10 research Python sources, configurations, derived numerical results and verification records, released at the research owner's request. No existing top-level license for MQ10 was found in the inspected project root. No new open-source license has been assigned or inferred. Rights remain with the respective holders; public availability alone would not grant general reuse permission. The owner should select and confirm code/result licensing before publication if open reuse is intended.

Third-party raw datasets, MATLAB code/packages, article PDFs, images, videos, connectome exports and fitted data objects are omitted. Original data/software DOI links are provided instead. Their current licenses and any attribution obligations for downstream derived results remain to be confirmed; this release does not assert that all third-party rights are cleared. No third-party license text is used to relicense the MQ10 code. A local content review found research-authored Python modules and imports rather than bundled third-party package implementations; this is not a legal ownership determination.

Personal filesystem locations and manuscript filename references in selected files were replaced by neutral placeholders. Scientific session/chain/draw/trajectory indices remain because they are required to interpret calculations. Secrets and personal location patterns are scanned over the exact allowlist and staged content before the first commit. The Git commit uses a neutral local author identity, avoiding a personal email in this new public history.
